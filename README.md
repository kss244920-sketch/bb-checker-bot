# BigBasket Enterprise Bulk Scanner & Auto-OTP Bot

Automated 24/7 BigBasket wallet and coupon checker bot with Render Keep-Alive, state recovery/persistence, and multi-Firebase panel parallel scanning.

## ✨ Features
- 💰 **Comprehensive Wallet & Balance Extraction**:
  - **Total Balance**: Complete usable funds.
  - **Free Cash**: Direct extraction of promotional Free Cash, bonus balance & shopping vouchers.
  - **Main Wallet**: Real deposited/refunded cash balance.
  - **Tata NeuCoins**: NeuCoins reward points breakdown.
- ⚡ **Scanner Hub**: Real-time multi-threaded scanning across Firebase RTDB panels with auto OTP verification.
- 📱 **Single Number Check**: Instant 1-on-1 verification with detailed balance card.
- 📥 **Export Hub**: Detailed `.txt` and `.csv` hits report export.
- 🔄 **24/7 Render Keep-Alive & Auto-Recovery**: Disaster recovery with silent cloud backup and auto-restart resilience.
